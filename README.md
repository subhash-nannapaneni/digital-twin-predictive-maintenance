# Digital Twin Simulation for Predictive Maintenance

## Overview

This project focuses on developing a digital twin simulation workflow for structural condition analysis using ANSYS Workbench 2023 R1. The objective was to evaluate the structural integrity and performance of a lifting lug under varying loading conditions using Finite Element Analysis (FEA) and analytical validation methods.

The project demonstrates how digital twin concepts can support predictive maintenance, stress analysis, and engineering optimization in industrial systems.

---

## Objectives

* Perform static structural analysis on a lifting lug
* Evaluate stress distribution under applied loads
* Analyze mesh convergence and optimization
* Compare FEA results with analytical calculations
* Explore predictive maintenance applications using digital twin concepts

---

## Tools & Technologies

* ANSYS Workbench 2023 R1
* Finite Element Analysis (FEA)
* Structural Steel Modeling
* Mesh Optimization Techniques
* Engineering Analytical Calculations

---

## Methodology

The analysis involved:

1. Geometry creation using ANSYS SpaceClaim
2. Material assignment and structural setup
3. Mesh generation and optimization
4. Application of boundary conditions and frictional contacts
5. Stress and deformation analysis
6. Mesh convergence validation
7. Comparison with analytical calculations based on EN 1993-1-8 standards

---

## Key Highlights

* Implemented tetrahedral and hexa mesh optimization techniques
* Reduced computational time while maintaining acceptable accuracy
* Conducted von Mises stress and mesh sensitivity analysis
* Validated simulation outputs using engineering analytical methods
* Applied digital twin concepts for predictive maintenance workflows

---

## Results

* Achieved less than 2% error between analytical and simulation results
* Optimized mesh configuration reduced computation time significantly
* Successfully identified stress concentration regions under load conditions

---

## Applications

* Predictive maintenance
* Structural health monitoring
* Industrial equipment optimization
* Mechanical component reliability analysis
